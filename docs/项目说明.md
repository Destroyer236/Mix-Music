# LinkLine 项目说明与使用手册

适用于 LinkLine 1.1 系列。当前版本：1.1.0，发布包面向 Windows 10 / 11 x64。

本地音乐、文件夹扫描导入、专辑 / 歌手搜索、播放详情链接、关闭窗口询问与应用内更新下载均已纳入正式发行版。最新变化见 [1.1.0 发行说明](releases/v1.1.0.md)和[更新日志](../CHANGELOG.md)。

1.1.0 更新推荐、搜索、歌单、排行榜、设置与播放详情界面，增加最近播放与图片主题配色，统一无描边浮动面板。默认点缀色和 Logo 为 `#00EB81`，面板圆角和间距均为 8 px；阴影、滚动条默认隐藏，左上角 Logo 固定，下方内容独立滚动。1.0.6 的本地音乐四种分类、桌面歌词悬停按钮、默认翻译与硬件加速设置继续可用。

LinkLine 将音乐发现、跨平台音乐库、本地音乐、播放和桌面歌词放在同一个桌面空间中。主界面与歌词窗口均使用重新设计的 Vue 界面，实际查询、播放、资料保存、下载和窗口控制通过 Electron 服务联动。

## 安装与首次使用

从[本项目的发布页](https://github.com/yaonikaixin999999/LinkLine/releases)下载 `LinkLine-v1.1.0-x64-Setup.exe`，运行后按提示完成安装。国内加速下载与备用入口见[README](../README.md#下载与安装)。新版安装程序包含中文许可文本编码修复。

首次启动会显示 LinkLine 使用协议。接受后出现一次性的账号连接引导，可直接打开「平台账号与红心」，也可先进入软件再配置。设置的第一个分类就是平台账号。

在线内容有两条使用路径：连接支持的平台账号，使用其接口与账号权限；或者在音源管理中导入自行准备的兼容音源脚本。软件不内置自定义音源脚本。两者都不改变歌曲版权或会员权限。本地音频可直接导入和播放。

## 主窗口与导航

| 区域 | 操作 |
| --- | --- |
| 左侧主导航 | 推荐、精选歌单、排行榜 |
| 左侧我的音乐 | 喜欢、最近播放、本地下载；本地下载页内切换「本地音乐 / 下载管理」 |
| 左侧歌单 | 自建歌单 / 收藏歌单切换、创建歌单；自建分组也包含已同步的平台歌单 |
| 顶部 | 页面返回、全局搜索、设置与偏好、外观定制、明暗切换、检查更新与窗口控制 |
| 底部播放栏 | 歌曲与封面、红心、播放控制、进度、歌词、队列、音质、播放模式与音量 |

拖动窗口顶部空白区域移动窗口；拖动四边或四角调整大小。右上角中间按钮在最大化和恢复之间切换，最大化时保留任务栏。`F11` 切换真正全屏，`Esc` 可退出全屏或关闭当前浮层。顶部或输入框内的可交互区域用于按钮和文字操作。

「常规与外观」可以配置默认窗口尺寸、字体与字体大小、动画、启动全屏、控制按钮位置、透明窗口及托盘行为。透明窗口配置需要重启生效。

1.0.6 增加「关闭硬件加速」，默认不勾选，即使用硬件加速。修改会先保存到本地，再弹出「修改已保存，是否立即重启 LinkLine 以生效？」；选择「立即重启」完整重启应用，选择「稍后」则在下次启动生效。软件渲染可能减少 GPU 内存占用，也可能增加 CPU 负担，实际效果以本机运行情况为准。

后台播放与托盘默认启用。点击右上角 X 或使用 `Alt + F4`，会询问是否关闭 LinkLine，可选择「取消」「退出应用」或「最小化到托盘」。最小化到托盘后播放继续，点击托盘图标可恢复窗口；托盘的「退出」会完全关闭应用。「不再询问」会记住所选的退出 / 托盘行为，之后可在「设置 → 常规与外观 → 关闭窗口时」改回每次询问。升级旧配置后会首次启用询问与托盘，之后保留用户自己保存的选择。

## 发现音乐、搜索与精选内容

### 发现音乐

「推荐」页展示按本地时间变化的问候、猜你喜欢、真实平台精选歌单与我的喜欢入口。歌曲推荐可选全部平台或指定平台，支持播放全部、单曲播放、收藏与换一批；根据已有收藏中的歌手作品和平台内容发现歌曲，暂无收藏时展示平台热播内容。

推荐历史保存在本机，换批与重启后继续用于减少重复；推荐仍由平台实际返回的候选内容组成，接口不可用时显示重试或切换平台提示。小窗口下音乐卡片可以横向浏览，歌曲推荐改为两列显示。

### 搜索

可以输入歌名、专辑、歌手或关键词，切换「歌曲 / 歌单 / 专辑 / 歌手」搜索，并选择「全部平台」或单独平台。全部平台请求中的部分平台失败时会显示其余已成功的结果及提示。支持搜索历史、单条移除和清空历史。

顶部输入框提供歌曲、歌手与关键词联想，歌手头像、歌曲封面按接口实际返回内容显示；支持上下键选择、Enter 打开、Esc 收起。点击歌手进入歌手目录搜索，点击歌曲进入相关歌曲搜索；接口暂不可用时仍可直接提交关键词。

歌曲结果支持播放单首、播放本页、收藏、加入歌单和下载。歌单结果可打开详情或直接播放。结果使用分页加载；网络失败时可重试或切换平台。

专辑和歌手分类查询平台真实目录。点击专辑卡片打开专辑曲目，点击歌手卡片打开该歌手的作品；详情支持播放、收藏、加入歌单、下载和分页。专辑目录支持 QQ、网易云、酷狗和酷我，歌手目录另外支持咪咕；哔哩哔哩没有音乐专辑 / 歌手目录，咪咕当前专辑目录接口不能稳定提供曲目，因此这两个分类只展示实际支持的平台。目录与曲目的可用性仍取决于平台接口和网络。

### 精选歌单

按平台、标签 / 分类和排序浏览精选歌单。也可以展开「打开已有的歌单链接或 ID」，粘贴所选平台的歌单地址或 ID。

歌单详情展示封面、作者、简介与歌曲列表，支持单曲播放、播放歌单、加入音乐库、分页、刷新、收藏、加入指定歌单和下载。将在线歌单加入音乐库后会创建本地歌单资料，不是复制平台的音频文件。

### 排行榜

切换平台，选择推荐榜单或「更多榜单」。可以播放单首或整个榜单、将榜单加入音乐库、刷新和翻页。榜单和精选歌单直接连接平台查询服务，平台接口临时不可用时会显示错误和重试入口。

## 平台账号、红心与歌单同步

### 登录与账号状态

进入「设置与偏好 → 平台账号与红心」，点击对应平台的登录按钮。软件打开平台的官方网页；扫码、账号密码、短信或安全验证以平台页面为准。LinkLine 主界面不接收网页登录表单中的账号密码。

支持验证的平台完成登录后会返回主窗口，并在账号卡片显示昵称与连接状态。账号页展示同步时间、红心数量、歌单数量和错误信息。登录失效后需重新登录。退出账号会移除此平台的聚合红心记录，主动保存在本地音乐库中的收藏继续保留。

| 平台 | 当前能力 |
| --- | --- |
| QQ 音乐 | 官方网页登录验证、红心同步、自己创建的歌单同步、红心操作、播放和音质查询 |
| 网易云音乐 | 官方网页登录验证、红心同步、自己创建的歌单同步、红心操作、播放和音质查询 |
| 咪咕音乐 | 官方网页登录验证、红心与自建歌单同步、红心操作、播放和音质查询 |
| 哔哩哔哩 | 官方网页登录验证、默认收藏夹聚合、自建收藏夹同步、收藏操作、视频音轨播放和音质查询 |
| 酷狗音乐 | 官方网页登录验证、公开播放接口；暂不支持网页账号的云收藏、创建歌单同步和红心写入 |
| 酷我音乐 | 官方网页登录入口、公开播放接口；暂不能验证网页账号连接，且不支持客户端收藏、歌单同步和红心写入 |

平台账号和播放的真实可用性取决于平台接口、账号权限与网络。尤其是需要会员、地区版权或安全验证的内容，软件不能代替平台授予权限。哔哩哔哩的收藏夹聚合与音乐平台红心不是同一种远端资源。

### 汇总我喜欢的音乐

点击单个平台的「同步音乐库」，或上方「同步全部」。软件读取支持平台的红心 / 收藏以及自建歌单信息，将红心汇总到「我喜欢的音乐」。同版本匹配使用歌名、歌手、时长和专辑等资料进行保守判断；匹配有歧义时保留各自记录，不强行合并不同版本。

同步操作主要读取平台资料；不会因为打开页面或点击同步就给远端歌曲加红心。网络失败时账号卡片显示原因，之前保存的离线记录会标明状态。

### 同时在多个平台加红心

点击歌曲列表或播放栏的红心时，LinkLine 保存本地收藏，并在已连接且支持收藏写入的平台查找同版本歌曲、检查可用权限，再逐个平台尝试收藏或取消收藏。

结果浮层分别显示成功、无版权 / 不可用、未匹配、匹配有歧义或请求失败。无法登录、未提供写入接口或没有合适版本的平台不会被标为成功。仅同步出歌曲不代表红心写入或播放权限始终有效。

### 平台创建的歌单

同步后，在主侧栏「自建歌单」分组查看平台创建的歌单或收藏夹。列表显示平台名称，打开时读取其歌曲；「同步歌单」可以重新加载。支持单曲播放、播放全部、搜索、排序、导出、批量收藏、加入本地歌单和下载。

平台歌单在 LinkLine 中主要作为同步视图。软件不提供在此直接重命名、删除远端歌单或移除其远端歌曲的操作。需要这些操作时请使用对应官方平台。

## 播放栏、队列与音质

### 基本播放

点击歌曲的播放按钮开始播放。播放栏中央提供上一首、播放 / 暂停、下一首，长进度条显示当前时间和总时长。拖动进度条可以跳转，点击歌曲封面或标题打开播放详情。

播放模式按钮依次切换列表循环、随机播放、单曲循环和顺序播放。队列按钮打开当前播放列表，点击条目切换歌曲；有临时稍后播放项时会单独显示。音量按钮展开二级浮层，可调音量和静音，支持键盘调整滑块。歌名下方提供喜欢、评论和更多操作；已收藏的红心显示为红色。

侧栏「最近播放」显示本机实际播放记录，支持搜索和重新播放；同一歌曲再次播放会移到前方，最多保留 500 条，重启后恢复。原歌单中的歌曲被移除时可能无法从记录回放，页面会提示失败。

「设置 → 播放」可以配置启动自动播放、保存与恢复进度、加载失败自动切歌、播放期间阻止休眠等行为。定时停止按分钟配置后点击「启动定时」，可取消，并可选择等待当前歌曲播完再暂停。

### 跨平台播放回退

原平台未返回可播放资源时，软件会尝试其他已接入平台的同版本歌曲，优先查询已连接账号的平台。匹配失败、版本有歧义或其他平台也没有权限时显示失败原因。回退成功后音质浮层展示实际播放平台。

自动匹配用于查找可正常播放的同版本资源，不保证每首歌曲都能成功，也不会绕过平台会员、区域或版权限制。

### 音质选择

播放栏的波形按钮打开音质浮层，可查询当前歌曲的平台音质。系统具备以下标签，但只有平台与歌曲实际提供的选项才会显示为可选音质：

| 类型 | 可识别的选项 |
| --- | --- |
| 常规有损 | 基础 64K、标准 128K、较高 192K、极高 320K |
| 无损与高解析 | FLAC、APE、WAV、Hi-Res 24bit |
| 平台特殊规格 | 杜比音频、高清环绕声、沉浸环绕声、超清母带 |
| 自动选择（默认） | 账号最高音质 |

默认使用「账号最高音质」，在当前歌曲和账号权限内选择最高可用档位。特殊音质是否可返回也由平台决定。选择更高档不等于购买会员，也不保证每个平台都提供同一档。

设置的「播放音质偏好」与播放栏共享一份配置，修改任意一处都会同步、保存并切换当前在线歌曲。切换时尽量保留播放位置以及暂停状态。若返回的实际规格低于请求档位，浮层会展示实际资源信息；失败时可重试或选择其他档位。本地文件按原始文件播放，不由这个选择器转换音质。

1.0.5 废弃旧播放栏独立保存的音质缓存，避免历史缓存覆盖默认选择；已在共享设置中主动保存的固定音质仍保留。要恢复自动选择，在设置或播放栏选择「账号最高音质」即可。

## 音乐库与本地音频

主侧栏统一展示「喜欢」「自建歌单」「收藏歌单」以及已同步的平台歌单；本地音乐从「本地下载 → 本地音乐」进入独立页面。左侧加号可新建本地歌单，右键本地自建或收藏歌单可播放、重命名和删除；平台同步歌单只提供可用的播放操作。本地音乐首次打开会汇总原有歌单与收藏中的本地歌曲，原列表和歌曲保留。

1.0.6 将「本地音乐」改为独立页面，统一从主侧栏打开，并删除「我的音乐库」内部重复的本地入口；旧链接会自动跳转。提供「全部歌曲」「歌手」「专辑」「文件夹」四种浏览方式；分类读取音频标签及文件所在目录，同名专辑按歌手区分，同名文件夹按完整路径区分。未填写的标签归入未知歌手、未知专辑；可编辑歌曲信息后重新归类，编辑仅修改 LinkLine 中的记录。

本地页面的搜索同时匹配歌曲、歌手、专辑、文件名和目录，搜索结果与当前分类取交集。点击歌手或专辑进入对应本地分类，点击歌曲或「播放全部」使用当前筛选结果生成队列，下一首继续播放该队列。支持选择全部筛选结果、批量加入歌单和移除；移除只删除本地曲库记录，其他歌单和电脑上的文件保留。页面显示真实文件格式，本地音质仍取决于原文件。

喜欢、最近播放、本地音乐和下载任务使用连续滚动列表，先展示 24 条，接近底部时继续追加；本地分类列表每批显示 100 项，可继续加载更多。完整索引保留给搜索、总数、批量选择和播放队列，界面分批展示不限制音乐库容量或导入数量。现有本地曲库及旧入口自动复用，不需要重新导入；独立页面随浅色、深色主题和外观偏好变化。

在「本地音乐」点击「导入音乐」可以选择多个音乐文件，点击「选择目录」可以选择一个 / 多个文件夹。文件夹会递归扫描子目录，分批读取歌曲资料并加入「本地音乐」，每次导入没有歌曲数量上限。导入中会显示已发现、已导入、跳过和失败数量，可点击「停止导入」；已完成的歌曲保留，之后再次导入会跳过它们。离开本地音乐页面也会停止当前导入。

扫描识别 `mp3`、`flac`、`ogg`、`oga`、`opus`、`wav`、`m4a`、`aac`、`ape`、`aiff`、`aif` 和 `wma` 文件。自动跳过重复路径、非音频文件和符号链接，不因个别文件损坏或目录无法读取而中断其余歌曲。具体能否解码取决于音频编码与运行时支持。导入保存文件路径和歌曲资料，不复制原文件；移动或删除原文件后需要重新导入。

歌单可以搜索、排序、分页、选择本页或多首歌曲，批量加入歌单、收藏、下载和移除。移除本地歌曲只删除歌单记录，原始音频仍保留。歌曲信息按钮可编辑本地库中的歌名、歌手和专辑资料，不代表修改远端平台数据。

「导入歌单文件」支持兼容的 `.lxmc` 与 `.json`。当前歌单可导出，完整资料导出在「备份与数据」。加入歌曲时，可以选择已有本地歌单，也可输入新歌单名称并创建。

「设置 → 音乐库」可设置列表来源信息、滚动位置恢复、操作按钮等行为，并编辑不喜欢与屏蔽规则。规则每行一条，形式为 `歌名`、`歌名@歌手` 或 `@歌手`，保存后播放会跳过匹配项。

## 音源管理与下载

### 自定义音源

进入「设置 → 音源管理」，导入兼容的 LX 音源 `.js` 文件，或者填写 HTTP / HTTPS 脚本地址并从链接导入。导入后点击「使用」，查看初始化状态。音源卡片展示名称、版本、作者与说明，并可打开主页、配置更新提醒和移除。

自定义音源代码会参与网络接口请求，应选择自己了解的来源。项目不附带可供用户使用的音源脚本。音源支持哪些歌曲、音质、下载能力和有效地址，取决于脚本本身及平台。

### 下载任务

在歌曲或批量操作中选择下载，弹窗展示当前音源支持的下载音质和保存目录。没有可用音质时会提示先配置支持该歌曲的音源。播放平台账号有可播放地址，也不代表自定义下载接口一定可用。

下载中心按全部、进行中、暂停、需重试和完成分类。任务显示已下载大小、总大小、进度和速度，支持单项或全部暂停 / 继续，失败重试，以及更改 / 打开下载目录。

完成任务可直接播放已保存文件、在文件夹中显示或加入本地歌单。移除已完成任务记录不会删除保存的音频。移除未完成任务则取消其队列记录。

「设置 → 下载」可配置下载启用、目录、命名方式、按歌单分组、并发数量、同名文件跳过、换源下载，以及歌词 / 翻译 / 罗马音保存、LRC 编码和音频封面 / 歌词嵌入。具体嵌入效果受格式支持影响。

## 播放详情、歌词与评论

点击播放栏封面或歌曲标题打开详情。详情采用唱片造型与按封面取色的独立背景，展示歌名、歌手、专辑、歌词和播放器；当前歌词在容器内居中滚动，歌词延迟与翻译控制位于歌词区下方。顶部收起按钮或 Esc 返回主界面。

播放栏评论按钮进入歌曲评论页，展示当前查看歌曲的资料和平台热门 / 最新评论；评论滚动到底部后连续加载，追加失败可以重试，播放下一首不会替换已打开的评论。评论以平台返回的数据为准，暂不可用时显示状态。

有歌手或专辑资料时，对应文字可以点击或通过键盘操作。点击后收起播放详情，进入相应的歌手 / 专辑搜索；缺少资料时不展示空链接。本地音频也可根据文件中读取到的歌手与专辑资料搜索在线作品。

歌词随播放滚动，可配置当前行缩放、字号、对齐方式、翻译、罗马音、简繁转换和卡拉 OK 歌词。在允许通过歌词调整进度时，点击歌词行可跳转到对应位置。歌词延迟按钮以 0.5 秒调整偏移。

1.0.6 默认显示平台提供的歌词翻译；之前主动关闭翻译的设置继续保留。可在「设置 → 歌词 → 显示歌词翻译」调整。

没有歌词的曲目会显示空状态；软件不会为每首歌自动生成歌词。

## 桌面歌词

点击播放栏歌词图标，或者在「设置 → 歌词」开启桌面歌词。它是独立的窗口，可在其他应用上方显示，并与当前歌曲和播放进度同步。

移动到歌词窗口可使用工具栏的上一首、播放 / 暂停、下一首、置顶、切换横向 / 纵向、偏好、锁定和关闭。解锁时可拖动与缩放；锁定后可通过解锁按钮或设置恢复。

1.0.6 的锁定按钮在鼠标移出歌词区域后隐藏，移入时重新出现；锁定后的穿透显示也可通过悬停找到解锁按钮。

歌词偏好提供字号、文字透明度和背景不透明度。**背景 0% 为全透明，100% 为不透明**，与歌词文字的透明度分别调整。窗口颜色、字体、间距、对齐、翻译 / 罗马音、音频可视化、置顶、任务栏显示、全屏 / 暂停隐藏及位置尺寸等可在设置中调整。

如果不知道歌词窗口在哪里，使用「设置 → 歌词 → 找回桌面歌词」。软件会将它移回当前屏幕、解除锁定并恢复可见背景。若设置了暂停或全屏隐藏，对应状态下窗口可能被主动隐藏。

## 外观定制

从顶部外观按钮，或「设置 → 常规与外观 → 外观定制」打开浮动面板。

| 选项 | 内容 |
| --- | --- |
| 主题 | 浅色、深色、自定义背景图片配色 |
| 点缀色 | 默认 #00EB81，预设颜色或自定义颜色；Logo 使用相同绿色 |
| 面板圆角 | 0–32 px，默认 8 px，侧栏、主面板、播放栏与弹出面板实时调整 |
| 浮动面板间距 | 0–32 px，默认 8 px；0 px 时去除内部边框与圆角接缝，面板无缝衔接 |
| 显示阴影 | 默认关闭，控制浮动面板、卡片与菜单的阴影 |
| 列表密度 | 舒适或紧凑 |
| 显示滚动条 | 默认关闭，隐藏侧栏、歌单、歌曲列表、歌词与弹出面板的滚动条，保留滚动操作 |
| 发现推荐 | 控制氛围与灵感内容显示 |

修改即时生效并自动保存；「恢复默认」重置外观配置。升级保留已有圆角、间距与自定义配色，新用户及恢复默认时使用新的默认值。顶部主题按钮可以快速切换浅色与深色。播放栏进度条在常规设置中可选择简洁、居中或完整宽度样式。

自定义图片主题支持选择本机 JPG、PNG、WebP 或 BMP 图片，最大 32 MB；图片保存在本地，自动提取颜色用于面板、文字与按钮，可选择自动、浅色或深色配色，也可更换图片或打开保存文件夹。

浅色主题主窗口背景为 `#F0F0F0`，浮动面板为 `#F6F6F6`，面板与弹出菜单均不显示外框描边。左上角 Logo 固定在侧栏顶部，下方导航与歌单独立滚动；窄窗口也可滚动访问全部歌单。

音乐库左侧歌单面板和右侧歌曲面板使用相同背景色，随浅色 / 深色主题同步变化。开启「显示滚动条」可以恢复列表滚动条显示，开关不会改变列表内容或滚动位置。

## 声音、快捷键与连接服务

### 声音与设备

「声音与设备」可调整输出设备、音量、静音、播放速率、音高补偿、音频可视化、最大输出声道数和设备变化暂停行为，提供均衡器各频段参数、预设选择、自定义预设保存 / 删除和均衡器重置，以及环境音效、3D 环绕与升降调设置。

高级音效启用时音频输出固定为系统默认设备。环境音效依赖对应文件和参数；各项效果仍由实际音频处理与设备能力决定。

### 快捷键

「快捷键」分为应用内和全局两组，可分别启用。点击输入框后按下组合键，离开输入框保存；`Delete` / `Backspace` 可清空绑定。被系统或其他应用占用的全局组合键会显示状态。

默认应用内快捷键：

| 按键 | 操作 |
| --- | --- |
| `Ctrl + F5` | 播放 / 暂停 |
| `Ctrl + ←` | 上一首 |
| `Ctrl + →` | 下一首 |
| `F1` | 聚焦搜索框 |
| `F11` | 切换全屏 |
| `Esc` | 退出全屏或关闭当前浮层 |

全局快捷键默认关闭；启用后可控制播放、切歌、音量、桌面歌词显示、锁定和置顶。实际绑定以设置页显示为准。

### 网络、设备同步与开放接口

网络设置提供接口请求代理的地址、端口和启用开关；它不代表所有网页或更新下载会使用同一个代理。

1.0.6 关闭听歌不需要的浏览器后台网络、扩展与投屏等服务。设备同步与开放接口默认关闭，按启用状态加载；下载 Worker 按任务需要创建。默认系统音频输出不发现或监听输出设备，选择具体设备、开启设备变化暂停或查看声音设置时才加载相关功能。正常音乐请求、平台登录和应用检查更新仍可使用。

设备同步用于自己的设备之间同步歌单与屏蔽规则，与平台红心同步不同。服务端模式显示地址和连接码，可刷新连接码、查看已配对设备并取消配对；客户端模式填写服务地址和连接码后连接验证。切换模式会关闭旧连接，保存配对信息。

开放接口启动本地 HTTP 控制服务，可配置端口和是否绑定局域网。状态区域显示实际服务地址和启动结果，用于第三方工具控制播放器；接口详情入口提供兼容 API 的说明。

安装包注册 `linkline://` 协议，供网页或其他工具唤起应用。兼容的链接可以控制播放器、传入歌曲资料或打开歌单；例如 `linkline://player/pause` 请求暂停当前播放。歌曲与歌单仍需要有效的平台标识和资料，错误链接会显示提示。

## 数据存储、备份与迁移

正式应用默认保存于 `%APPDATA%\LinkLine`，音乐资料在 `LxDatas` 子目录。平台网页登录会话使用本机独立的 Electron 会话分区；没有配置 LinkLine 自有账号服务器来上传平台账号和资料。

「备份与数据」包含完整备份、音乐库备份和偏好设置备份，各自支持导入与导出。完整备份包含歌单、设置和现代外观；音乐库备份包含试听、收藏及个人歌单；偏好设置备份包含支持的应用偏好和现代外观。也可以导出歌单文本或 CSV。

兼容的 `.lxmc` 导入中，同 ID 自建歌单内容会被覆盖，其他歌单保留；固定「本地音乐」栏目采用合并，并汇总恢复歌单中的本地歌曲。导入设置只恢复当前支持的偏好，不修改版本和协议接受状态。覆盖或清空操作有确认弹窗。

资料备份不包含音频文件本体，也不是平台 Cookie 或登录会话的备份。迁移电脑时应额外复制本地音乐文件，在新电脑重新连接平台；原音频路径变化后要重新导入。

可查看并清理图片资源、换源匹配、播放地址、原始歌词和已编辑歌词缓存。「清空音乐库」会删除歌单、试听和收藏资料，操作前请先导出备份。

源码测试脚本默认使用项目的 `artifacts/user-test-data`，与正常安装的目录不同。支持通过 `LINKLINE_DATA_DIR` 指定资料目录；使用指定目录前先退出所有使用该目录的 LinkLine 进程。安装或升级时不要手动删除已有资料目录。

## 更新中心与国内下载

每次打开 LinkLine 都会在后台检查本仓库正式版本，检测到新版本时自动打开更新中心。点击顶部云下载按钮、设置中的「检查更新」，或关于页的检查按钮，打开同一更新中心。

更新中心显示当前版本、最新正式版本、上次检查时间、更新日志、历史版本和检查状态。状态包括已是最新、有新版本、尚未发布及失败。发现新版本时顶部显示提示点；网络失败可重试。

国内检查源读取本仓库 `updates/stable-linkline.json`，先通过第三方 gh-proxy.com，失败时尝试 ghfast.top，再回退 GitHub 官方。可选择官方源；官方检查使用本仓库 GitHub Releases，并可尝试其正式发布订阅。只检查本项目，不读取原版应用的版本渠道。草稿与预发布版本不作为正式升级。

GitHub 仓库已更名为 `LinkLine`，1.0.2 及更新版本的官方检查与项目链接使用新地址。已发布的 1.0.0 / 1.0.1 仍通过旧国内入口读取兼容清单 `updates/stable.json`；发布时同时维护两份清单。旧版官方检查可能无法识别改名后的地址，请切换国内更新源，或从本项目发布页直接下载 1.1.0 安装包升级。

从 1.0.4 起，下载按钮会在应用内下载同一官方 Windows x64 安装包，显示进度、已下载大小和速度，无需跳转浏览器。国内源使用第三方加速地址，「国内备用下载」切换到备用代理。它们不是 LinkLine 自建的国内服务器；服务可用性和速度随地区及网络变化。「打开官方下载页」可在浏览器中查看 Release 和其他文件。

默认选择「国内加速（第三方）」，切换到「GitHub 官方」后会保存偏好。版本信息如果经过回退取得，页面会显示实际来源；选择国内加速时，下载仍使用国内入口。

有 Windows x64 安装包时显示下载按钮，没有安装包时可打开官方下载页。下载完成后显示「安装更新」，点击后 LinkLine 会退出并启动安装程序。下载失败可以重试；发布清单提供 SHA-256 时，下载会校验文件并显示结果，也可以展开「查看 SHA-256 校验值」。通过浏览器下载时，Windows PowerShell 可执行：

```powershell
Get-FileHash -LiteralPath '.\LinkLine-v1.1.0-x64-Setup.exe' -Algorithm SHA256
```

与更新中心或发布页的 SHA-256 一致，表示下载文件与发布文件一致。

发布页同时提供 `SHA256SUMS.txt`，可用于从浏览器直接下载后的校验。

1.x 系列使用完整安装包升级。应用内下载后由用户点击安装并完成安装向导；从浏览器下载安装包时，先从托盘退出旧版再运行。软件不会在后台自动安装。新版正式发布信息由仓库版本清单和 Release 维护。

## 常见问题

**安装程序许可正文中文乱码。** 1.0.2 已修复许可文本编码，1.1.0 安装包沿用该修复。关闭旧安装程序，重新下载并运行 1.1.0 安装包。

**同步有歌曲，但是播放失败。** 同步读取的是音乐资料；播放还需平台返回资源。先检查账号连接，再尝试音质自动档、其他平台或自己的音源。确认失败原因，不能将平台权限缺失当作已解决。

**某个平台已经登录，但没有收藏同步。** QQ、网易云、咪咕和哔哩哔哩提供对应接口；酷狗、酷我当前不支持云收藏同步。对支持的平台，完成官网的安全验证并重新同步，查看账号卡片的具体错误。

**下载弹窗没有音质。** 下载依赖当前自定义音源的下载能力。先启用下载、配置目录并导入支持该歌曲的音源；在线可播放不代表此下载源一定可用。

**找不到桌面歌词。** 使用设置中的「找回桌面歌词」，检查背景不透明度以及暂停 / 全屏隐藏选项。

**关闭窗口后还有声音。** 如果关闭行为配置为托盘，应用仍在运行。从托盘退出即可完全关闭。

**检查更新或加速下载失败。** 重试，切换官方源或国内备用入口。代理属于第三方服务，不能保证长期可用。

**为什么任务管理器显示多个进程或较高内存？** LinkLine 使用 Electron，主进程、主界面、GPU、歌词与平台登录窗口等会单独占用内存。1.0.4 / 1.0.5 修复了查询和播放资源的累积，减少频谱的无效绘制，限制平台与音效缓存，并改为按需创建下载 Worker。总占用仍受封面、音效、打开窗口和使用时长影响，不能用固定数值衡量所有使用场景。如果占用持续增长，请记录版本、运行时长、页面和启用的音效或歌词选项，便于排查。

1.0.6 进一步限制 JavaScript 堆与歌单、封面地址的缓存保留，减少默认听歌场景的服务加载。「512 MiB」是单个 V8 旧生代预算，并非整个软件的内存上限。测量口径和限制见[性能优化说明](性能优化说明.md)。
