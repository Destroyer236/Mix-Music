# Mix Music 1.3.4

发布日期：2026-10-27。

Mix Music 1.3.4 为下载补全了音源级联：开启换源下载后，本源拿不到的音质会先降档，其他音源按各自可提供的最高音质参与竞争。

## 下载音源级联

- 开启「歌曲源不可用时，是否启用换源下载」后，下载取链接的级联变为：先在本源沿该歌曲可用的音质从高到低依次尝试；仍拿不到时，其他已登录音源与导入音源并行解析，各源自带不超过任务音质的最高档，由解析器按实际返回的音质择优。
- 试听片段不再直接采纳：高音质只返回试听时，会继续向低音质尝试拿完整音频，找不到才用试听兜底。
- 该级联只作用于下载取链接；播放的取流行为保持不变。

## 说明

- 当前安装包面向 Windows 10 / 11 64 位（x64）。
- 1.3.3 及更早版本仍可从本仓库的发布页获取。
