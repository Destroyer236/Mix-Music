# Mix Music 1.3.0

发布日期：2026-10-26。

Mix Music 1.3.0 是更名后的第一个正式版本。应用由 LinkLine 正式更名为 Mix Music，播放、平台账号与歌单功能保持不变，已有数据会自动迁移。

## 品牌更名

- 应用名、安装程序、窗口标题、托盘提示与歌词窗口统一为 Mix Music；应用标识改为 `com.mixmusic.desktop`。
- 侧栏字标改为随主题色变化的 Mix Music 排版，替换原有的 SVG 字形；安装包与图标同步更新。
- 应用图标重新设计：白底圆角方块、同心圆衬底、深色「Mix」与品牌绿「MUSIC」，小尺寸下自动切换为单行徽记，保证任务栏与开始菜单中清晰可辨。
- 欢迎协议、关于页、关闭确认、更新中心与设置提示文案全部同步为新名称。
- 关于页新增「本项目参考」，说明界面设计参考的 EchoMusic 与项目上游 LinkLine。

## 数据与兼容

- 用户数据迁移到 `%APPDATA%\Mix Music`。首次启动时若检测到旧的 `LinkLine` 或 `LX Studio` 目录，会自动复制其中的账号登录状态、歌单与设置，无需重新登录。
- 新增 `mixmusic://` 协议唤起；旧的 `linkline://` 链接继续有效。
- 更新器同时识别新版本安装包与改名前的历史安装包，旧版本用户可以在应用内直接升级。
- 平台登录 Cookie、应用内设置与本地曲库的记录标识保持原样，升级不会导致账号失效或设置丢失。

## 平台歌单写入

- 现在可以直接把歌曲添加到已连接平台的歌单：在歌曲的「加入你的歌单」弹窗中先选择平台，再选择歌单即可写入。
- 已支持网易云音乐、哔哩哔哩、波点音乐、QQ 音乐、咪咕音乐与酷狗概念版；汽水音乐、酷狗音乐与酷我音乐暂不支持写入，界面会说明原因。
- 跨平台歌曲会先在目标平台匹配同版本歌曲并检查版权，无法确认时不写入，避免加错版本。
- 加歌成功后歌单内容按服务端实际结果刷新，不猜测歌曲数量。

## 酷狗概念版

- 新增酷狗概念版账号：扫码登录后可同步歌单、同步红心、添加歌曲并领取会员。
- 概念版与酷狗音乐是两个独立账号，登录与能力互不影响；概念版只负责账号、歌单与写入，播放仍由酷狗音乐提供。
- 账号卡片显示会员等级与到期时间。

## 侧栏

- 侧栏歌单按来源分组显示：本地自建歌单在前，其后是各已连接平台的歌单，分组标题标注平台名称。

## 说明

- 当前安装包面向 Windows 10 / 11 64 位（x64）。
- 1.2.1 及更早版本仍可从原 LinkLine 仓库的发布页获取。
