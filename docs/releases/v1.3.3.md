# Mix Music 1.3.3

发布日期：2026-10-27。

Mix Music 1.3.3 修复了从平台歌单下载歌曲必然失败的问题，并新增可选的「自动选择下载音质」。

## 下载修复

- 修复平台歌单（酷狗概念版等同步回来的歌单）里的歌曲点击下载时报 `Failed to execute 'postMessage' on 'Worker': could not be cloned` 的问题：这些歌曲对象以 Vue 响应式代理的形式进入下载流程，跨线程传参时无法被克隆。现在创建下载任务前统一深拷贝为纯数据，并补充回归测试防止复发。

## 新功能

- 新增「自动选择下载音质」设置（默认关闭，位于 设置 → 下载）。开启后，下载弹窗与播放器的下载页提供「自动」入口：每首歌按其最高可用音质入队，该音质实际不可用时依次向下一档递减，多选歌曲不再要求共享同一音质。

## 界面

- 歌曲列表表头不再使用独立的不透明底色，改为跟随页面背景，两种皮肤下都不再出现与周围不连续的实色横条。
- 修复 EchoMusic 皮肤下歌单页与本地音乐页内容区被不透明底色盖住、氛围渐变中断的问题，页面背景现在从头到尾连续。
- 本地曲库的固定表头改用面板表面色，在自定义壁纸模式下与背景协调。

## 说明

- 当前安装包面向 Windows 10 / 11 64 位（x64）。
- 1.3.2 及更早版本仍可从本仓库的发布页获取。
