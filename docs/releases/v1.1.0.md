# LinkLine 1.1.0

发布日期：2026-10-13。

LinkLine 1.1.0 更新主要前端页面，采用绿色点缀、无描边浮动面板和固定侧栏 Logo。推荐、搜索、歌单、设置与播放详情使用统一布局，继续连接现有平台账号、音乐库与播放服务。

## 页面与交互

- 推荐页展示真实平台精选歌单、猜你喜欢、热播歌曲和收藏歌手作品；支持全部平台或指定平台、换一批、单曲 / 全部播放与收藏。本机保存推荐历史，减少换批和重启后的重复推荐。
- 主侧栏统一为推荐、精选歌单、排行榜、喜欢、最近播放和本地下载；自建 / 收藏歌单分组支持切换，已同步的平台自建歌单一并展示。本地下载页内可切换本地音乐与下载管理。
- 顶部集中提供全局搜索、设置、外观、明暗切换、检查更新与窗口控制。搜索输入联想展示歌曲、歌手与关键词，支持上下键、Enter 和 Esc；保留歌曲 / 歌单 / 专辑 / 歌手搜索。
- 精选歌单使用封面网格与可展开的分类面板，排行榜改为紧凑榜单导航；歌单封面使用实际歌曲封面，侧栏本地歌单可右键播放、重命名和删除，平台同步歌单提供播放操作。
- 增加持久化最近播放页面，支持搜索与回放。喜欢、最近播放、本地音乐和下载任务使用连续滚动、分批展示，完整曲库继续用于搜索、批量选择和播放队列。
- 调整底部播放器、音量、音质和播放队列浮层；播放详情采用唱片造型、封面取色背景与居中滚动歌词。评论独立成页，滚动到末尾后连续加载；已收藏歌曲使用红色实心红心。
- 设置分类保持单行横向导航，点击定位分区，内容滚动时同步高亮。新增自定义图片主题，按本机背景图片自动生成面板、文字与按钮配色，并可调整明暗。

## 默认外观与面板修复

| 项目 | 1.1.0 默认值 / 行为 |
| --- | --- |
| 点缀色与 Logo | `#00EB81`；应用内与系统图标同步更新 |
| 浅色窗口背景 | `#F0F0F0` |
| 浅色浮动面板 | `#F6F6F6` |
| 面板外框 | 侧栏、主内容、播放栏与弹出面板无描边 |
| 面板圆角 | 8 px，可在 0–32 px 调整 |
| 面板间距 | 8 px，可在 0–32 px 调整；0 px 时无缝衔接 |
| 显示阴影 | 默认关闭，可在外观定制开启 |
| 显示滚动条 | 默认关闭，可在外观定制开启；隐藏时仍可滚动 |
| 侧栏 Logo | 固定在顶部，下方导航和歌单独立滚动 |

修复了间距设为 0 px 后仍因相邻面板边框和圆角出现接缝的问题。圆角、间距与开关实时生效并保存，普通与窄窗口、浅色与深色主题均适用；图片主题继续使用从图片提取的配色。

升级会保留已保存的点缀色、圆角和间距。希望使用新版默认外观时，打开顶部「外观定制」，点击「恢复默认」。
