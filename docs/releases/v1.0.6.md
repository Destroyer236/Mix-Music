# LinkLine 1.0.6

LinkLine 1.0.6 将本地音乐整理为独立页面，提供歌曲、歌手、专辑和文件夹分类；同时改善桌面歌词操作，并减少普通听歌场景下的资源驻留。

## 更新内容

- 独立本地音乐页面提供「全部歌曲」「歌手」「专辑」「文件夹」四种分类、本地搜索、分类播放队列、目录递归导入、歌曲信息编辑及批量加入歌单、移除。分类读取音频标签与完整文件路径，保留已有曲库和原音频文件。
- 删除「我的音乐库」内部重复的本地音乐入口，统一从主侧栏进入独立页面；旧本地音乐链接自动跳转。
- 桌面歌词右上角锁定按钮在鼠标移出歌词区域后隐藏，移入时显示；锁定后也可通过悬停找到解锁按钮。
- 默认显示平台提供的歌词翻译，保留用户之前主动关闭翻译的设置。
- 「设置 → 常规与外观」新增「关闭硬件加速」，默认不勾选，即使用硬件加速。配置先保存到本地，再弹出「修改已保存，是否立即重启 LinkLine 以生效？」；「立即重启」完整重启应用，「稍后」在下次启动生效。
- 设备同步、开放接口、下载及本地资料 Worker 按需要加载。默认系统输出不枚举或监听音频设备；具体输出设备和移除暂停功能需要时才启用发现。关闭听歌不需要的 Chromium 后台网络、扩展、投屏和自动填充通信，音乐请求、平台登录与应用更新继续可用。
- V8 旧生代预算设为 512 MiB；数据库歌单缓存与封面地址缓存设为有数量和估算容量预算的 LRU，减少已浏览资料的长期驻留，不限制曲库或导入歌曲数量。

**512 MiB 是单个 V8 旧生代预算，不是整个软件的内存上限。** 当前运行时报告的总堆上限约 608 MiB，原生音频、图片、GPU 与其他进程另计。关闭硬件加速的实际效果取决于设备，可能增加 CPU 负担，不能保证所有机器都会更省内存。测量方法与本机样本见[性能优化说明](https://github.com/yaonikaixin999999/LinkLine/blob/main/docs/性能优化说明.md)。

## 验证

- 自动回归测试：297 项通过。
- 大型本地音乐库验证：分类、搜索和缓存保留预算不限制完整曲库读取及导入。
- 实际桌面运行验证：本地音频播放与队列、桌面歌词悬停解锁、硬件加速配置保存及重启行为。
