# LinkLine 1.2.0

发布日期：2026-10-17。

LinkLine 1.2.0 重做播放器及其子菜单，加入三种外部歌词、网易云心动模式和全局首选音源，改进推荐续播与长歌单滚动。播放器背景和面板跟随软件主题，原有评论页面继续保留。

## 沉浸播放器

- 新播放器提供方形封面、黑胶唱片、全屏封面三种布局，可选择软件主题、封面模糊或流动光影背景；适配浅色、深色与图片主题。
- 加入页面展开、切歌、歌词 / 队列切换及子菜单动画。沉浸模式下，闲置时操作栏和歌词工具一起淡出，移动鼠标后恢复；可选音频频谱，无歌词时可自动居中封面。
- 歌曲信息展示实际播放的音源来源、音质和试听状态。音质文字标签仅作标识，音质切换从操作栏入口进入。
- 播放按钮左侧统一切换列表循环、随机播放、单曲循环和顺序播放，右侧直接调整音量。下载入口收纳至「更多」菜单。
- 「更多」提供音频信息、均衡器、播放速度、独立升降调、A/B 片段循环、定时暂停、播放器外观、输出设备、首选音源、下载、加入歌单和复制歌曲链接。
- 队列支持搜索、定位当前歌曲、移除歌曲与清空队列，并展示「稍后播放」；队列操作保留原歌单与本地文件。
- 修复歌词与队列滚动后，右侧顶部空白区域无法拖动窗口的问题；修复当前歌词悬停背景的右侧圆角。

## 歌词与外部窗口

- 播放器歌词支持逐字高亮、翻译与罗马音、点击歌词跳转、手动滚动后回到当前行，以及歌词偏移调整。
- 歌词设置增加上下间距滑条和对齐选项；默认字号为 32，上下间距为 18 px，默认开启非当前歌词模糊。已有保存值继续生效。
- 可选择歌词行、全选或反选，复制歌词、复制原始歌词，或将所选歌词导出为图片。
- 桌面歌词、灵动岛歌词、任务栏歌词可独立开启、同时显示，共享当前歌曲与播放进度，分别保存外观和交互偏好。
- 桌面歌词支持逐字、双行、翻译、字体与颜色、置顶、锁定和背景遮罩；灵动岛支持弹性 / 平滑切换、顶部吸附与鼠标穿透。
- Windows 任务栏歌词按任务栏可用空间布局，可设置封面、字号、颜色模式与边距。空间不足或竖向任务栏时隐藏显示。
- 统一播放栏与播放器的外部歌词菜单；设置中的三种歌词分区增加间距，保留旧桌面歌词开关、快捷键及备份兼容。

更多设置与平台差异见[外部歌词说明](https://github.com/yaonikaixin999999/LinkLine/blob/main/docs/external-lyrics.md)。

## 网易云心动模式

- 在侧栏「喜欢」右侧嵌入心动模式按钮。未连接网易云音乐时，点击会提示登录网易云音乐。
- 登录后，优先使用当前网易云歌曲作为种子；没有适用歌曲时，从该账号喜欢的歌曲中选择种子，调用网易云心动推荐生成播放队列。
- 再次点击可退出心动模式，保留已经载入的队列与当前歌曲。切换其他播放队列、切换不兼容的播放模式或更换网易云账号时退出。
- 心动模式依赖网易云账号、喜欢的音乐歌单及平台推荐结果；没有可用结果时显示具体提示。

## 音源、平台与歌曲信息

- 「音源管理」与「播放」统一为「音源与播放」，集中设置音乐接口、首选音源、音质、播放顺序、进度恢复和定时停止。
- 可为播放设置全局首选音源。默认跟随歌曲来源；所选平台不可用时尝试其他平台的同版本歌曲，完整音频优先于平台允许的试听片段。
- 歌曲列表增加来源、VIP 标识及版本副标题，长歌名提供完整内容提示；试听标识依据实际播放资源显示。
- 新增汽水音乐与波点音乐实验性适配，提供扫码登录、搜索、歌单导入、歌词与官方音频接口，并接入音乐库同步及收藏操作。设置中的账号顺序调整为 QQ 音乐、网易云音乐、汽水音乐、波点音乐，再到其他平台。

汽水音乐使用抖音 App 扫码，波点音乐使用波点 App 扫码。两者已验证公开接口、二维码及模拟账号流程，真实账号授权后的登录、同步与收藏写入仍需实号测试。汽水分享接口不提供原生无损 / Hi-Res 音质切换；加密或版权受限内容不会作为完整音频播放。

## 推荐、队列与列表体验

- 推荐页播放卡片与当前歌曲、封面和播放状态同步。推荐、搜索和最近播放按所选列表建立队列，上一首 / 下一首沿用该队列；浏览或换一批不会打乱已经开始的播放。
- 推荐续播在剩余歌曲不超过 3 首时提前准备下一批，减少播放到批次末尾后的等待；各推荐分区预备备用内容，结合收藏和最近播放减少重复。
- 修复异步切歌时旧封面、歌词或播放请求覆盖新选择的问题，区分不同平台的相同歌曲 ID；顺序播放到最后一首后暂停。
- 喜欢和歌单详情增加滚动折叠头部，歌曲列表使用虚拟滚动，减少长列表挂载；增加定位当前歌曲和回到顶部按钮。
- 主要模块切换增加淡入淡出，并跟随动画设置与系统减少动态效果偏好。精简外观定制面板，弹出面板背景随主题变化。
