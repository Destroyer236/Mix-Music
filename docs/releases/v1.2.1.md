# LinkLine 1.2.1

发布日期：2026-10-20。

LinkLine 1.2.1 更新「拍点」Logo 与 LinkLine 字标，改进任务栏歌词恢复、平台扫码登录和在线音频获取，并调整播放器操作与推荐反馈。

## 品牌与播放器

- 换用纯色「拍点」Logo 和几何 LinkLine 字标，同步应用、安装包及托盘图标。左上角品牌缩小并靠左排列，窄窗口保留图标。
- 调整播放详情中的歌词、播放队列与更多功能入口；收起按钮位于顶部，播放队列位于底栏最右侧，歌词显示开关与外部歌词入口分别控制。
- 歌词区右侧工具栏提供设置与更多功能；相关浮层跟随播放详情的主题配色，保留歌词字号、间距、对齐和动画偏好。
- 「更多操作」增加「减少推荐」：将歌曲写入本机不喜欢库，当前正在播放该歌曲时跳到下一首；后续推荐、预加载和推荐续播排除匹配项，可在设置中管理规则。
- 调整歌单详情底部留白与批量选择操作区域，侧栏歌单封面在无图片时显示占位图。

## 外部歌词

- 恢复简洁的外部歌词菜单和图标，桌面歌词、灵动岛与任务栏歌词继续独立开关。
- 改进 Windows 任务栏歌词嵌入、空闲区域计算与窗口恢复：任务栏重建、宿主失去响应或歌词渲染进程退出时自动尝试恢复，减少切换其他应用后歌词消失的情况。
- 修复任务栏歌词的翻译依赖「双行歌词」开关的问题。有当前行翻译且开启翻译时，关闭双行也显示翻译；没有翻译时，双行开关决定是否显示下一句。
- 修复部分屏幕缩放比例下，桌面或灵动岛歌词移动后窗口尺寸因取整逐渐增大的问题。

任务栏歌词仍仅支持 Windows；任务栏空间不足或竖向布局时隐藏。更多配置见[外部歌词说明](https://github.com/yaonikaixin999999/LinkLine/blob/main/docs/external-lyrics.md)。

## 登录与音质

- QQ 音乐和网易云音乐改用应用内二维码登录：QQ 音乐使用手机 QQ 扫码，网易云使用网易云音乐 App 扫码；支持刷新、过期与关闭流程，验证账号后同步音乐库。
- 汽水音乐使用汽水音乐 App 的「扫一扫」。接入官方登录安全组件，平台要求验证码或身份验证时显示独立的官方安全验证窗口，完成后继续查询登录状态。
- 汽水扫码查询在临时受限时等待并自动重试，展示查询阶段与平台错误码；关闭、刷新或退出账号会取消旧流程，避免旧请求覆盖新状态。
- 网易云音乐使用专门的音质详情接口，补充高清臻音、沉浸环绕声、超清母带等规格的识别与展示，自动音质按实际返回资源选择可用档位，并优先完整音频。
- 识别网易云臻音全景声（Audio Vivid），但当前播放器不支持其 AV3A 编码，该选项显示为不可选，自动选择也会跳过。

## 在线播放与音源

- 改进汽水音乐音频解析，支持分享页刷新、普通歌曲与原声片段（UGC）的媒体类型识别，并读取官方播放器返回的主备音频候选。
- 检查候选音频的歌曲 ID、完整时长、试听及保护状态；在实际播放会话中探测音频连接，避免单个失效或无法连接的 CDN 地址遮住其他有效候选。
- 在线音频加载或解码失败时，排除已失败地址并尝试重新解析及换源，减少持续复用失效缓存；保留现有完整音频优先和播放状态恢复规则。
- 全局首选音源支持选择已导入的音源；自动时优先使用歌曲所属的已登录平台，否则从及时响应的完整资源中优选音质。
- 默认音源入口按需下载并缓存远程脚本；改进导入音源的播放、下载能力识别，以及歌曲资料与音源参数的传递。
- 更新中心支持排版显示发行说明与历史版本内容。

汽水的网页播放权限与 App 权限可能不同。受保护音频、仅试听资源、数字专辑授权或地区版权限制仍可能导致无法播放；本次更新不代表所有汽水歌曲可播。扫码安全验证的出现时间取决于平台返回结果，真实账号、会员音质及各平台接口仍受账号权限与网络影响。
