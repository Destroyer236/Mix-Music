# Mix Music 1.3.1

发布日期：2026-10-26。

Mix Music 1.3.1 修复了平台歌单的显示逻辑，收藏歌单现在会进入侧栏的「收藏歌单」分区，不再与自建歌单混在一起或直接消失。

## 歌单分区

- 侧栏「自建歌单」只显示你在各平台创建的歌单，「收藏歌单」显示你收藏的他人歌单，两个分区都按平台分组。
- 修复酷狗概念版收藏歌单被过滤掉的问题：此前用创作者 ID 判断归属，该字段对收藏歌单同样等于当前账号，导致筛选逻辑失效。
- 网易云音乐此前会丢弃所有非本人创建的歌单，现在会保留并归入「收藏歌单」。
- 波点音乐区分「我创建的」与「我收藏的」两个接口来源。
- 咪咕音乐读取收藏歌单列表，并修复歌单内容因原作者 ID 校验而无法打开的问题。
- 哔哩哔哩同时拉取创建与收藏的收藏夹，收藏项不再被账号归属校验拦下。
- QQ 音乐不再丢弃收藏歌单；但其账号接口目前只返回自建歌单，收藏歌单需要平台提供额外接口。

## 已知限制

- 汽水音乐的歌单接口只返回本人歌单，暂无法列出收藏的他人歌单。
- 酷狗音乐与酷我音乐未提供歌单接口，维持只读或不可用状态。

## 其他

- 关于页显示作者 Zephyr，可点击打开作者主页。
- 欢迎协议、开源许可弹窗与安装程序许可文件标注作者信息。
- 当前安装包面向 Windows 10 / 11 64 位（x64）。
- 1.3.0 及更早版本仍可从本仓库的发布页获取。
