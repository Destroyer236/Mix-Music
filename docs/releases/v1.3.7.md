# Mix Music 1.3.7

发布日期：2026-10-29。

Mix Music 1.3.7 修复了汽水音乐「抖音收藏的音乐」歌单同步失败的问题。

## 抖音收藏歌单修复

- 平台对空的「抖音收藏的音乐」歌单不再返回歌曲数组，也不返回歌曲数量与翻页标记，导致同步时报「汽水音乐未返回歌单歌曲」。现已将这种响应正确识别为空歌单，同步正常完成并显示 0 首歌曲。
- 若服务端声明歌单有歌曲但未返回内容，仍然会明确报错，不会静默丢失歌曲。

## 说明

- 当前安装包面向 Windows 10 / 11 64 位（x64）。
- 本版本继续提供增量更新：从 1.3.6 升级到本版本只需下载变化的字节。
